# Expense Tracker — React.js

A beginner-friendly Expense Tracker built with Vite + React + JavaScript.

## Features

- Add expenses
- Edit expenses
- Delete expenses
- Search expenses
- Filter by category
- Sort by date, amount, or title
- Total expense, transaction count, average expense and category count
- Category-wise expense breakdown
- Form validation
- Responsive design
- Mock API loading using `useEffect`
- Local browser persistence using `localStorage`
- `useState` for application and form state
- `useEffect` for mock API loading/saving
- `useRef` to focus the expense title input
- `useMemo` for filtered data and totals
- `useCallback` for event handlers

## Requirements

Install Node.js (LTS recommended).

## Run in VS Code

Open the project folder in VS Code, then open the terminal:


npm install
npm run dev
